# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-17

### Added

- Initial open-source release accompanying the IEEE RAL 2026 paper.
- VLM-based task planning pipeline with short-term and long-term memory.
- Scene description, action planning, success detection, and experience summarization modules.
- Long-term memory management with text embedding retrieval (RAG).
- Gradio web UI for interactive task instruction and conversation log viewing.
- Gradio UI for LTM inspection and cosine similarity visualization.
- Rosbag replay support for running the pipeline without a physical robot.
- Analysis scripts for figure generation and log inspection.
